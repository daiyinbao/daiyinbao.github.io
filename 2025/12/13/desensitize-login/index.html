微服务下的登录模块详解

2025-12-13

一.微服务下的登录模块

​ 本文基于一个真实的企业级 IAM（Identity & Access Management）项目，系统性拆解登录模块在高并发、高安全场景下的设计思路与工程实现

目标读者：

  • 有一定 Spring Boot / Java 后端经验
  • 希望把“能用的登录”升级为“可扩展、可风控、可演进的登录体系”1

1.模块划分

1.1网关模块gataway-service

该模块主要用于接收前端发过来的请求，分发请求需要业务到对应模块。

该模块的功能：

分发请求。使用spring cloud alibaba gateway 组件实现请求分发

辨识token的合法性。

使用openfeignn 实现模块之间的功能调用

这篇文章对该模块不做详细讲解！

1.2 业务模块iam-service

该模块是完成登录相关业务的主要处理模块

当网关的请求到达该业务时，会根据api调用不同的service，完成用户需求。并将数据返回给前端，是核心的业务层！

2.实现业务前瞻

业务层：

0客户端请求
↓
① 图形验证码校验
② 短信验证码校验
③ 解析客户端 IP
④ IP 白名单 / 黑名单校验
⑤ 密码复杂度校验
⑥ Redis 登录互斥锁
⑦ 是否已登录校验
⑧ 查询用户
⑨ 账号是否被锁定
⑩ 密码是否过期
⑪ 校验密码
├─ 失败 → 失败次数 + 账号锁定
└─ 成功
⑫ 重置登录状态
⑬ 生成 JWT（access + refresh）
⑭ 绑定 Redis Session（单端登录）
⑮ 清理旧 Token
⑯ 缓存新 Token
⑰ 返回登录结果
